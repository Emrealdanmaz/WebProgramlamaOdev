PHP 8.2 ile B2B Toptan Altyapısından B2C Perakende E-Ticaret Mimarisine Geçiş

Mevcut B2B/POS veritabanı şemasını bozmadan B2C son kullanıcı vitrinine dönüştürme, PDO güvenliği ve 3:4 stüdyo kadrajında otomatik görsel işleme hattı.

Halihazırda mağaza içi barkodlu satış (POS), cari hesap ve toptan sipariş yönetimi için çalışan bir PHP/MySQL sistemini son kullanıcıya (B2C) açarken en kritik hedef, arka plandaki stok ve fiyat tablolarını çoğaltmadan tek veritabanı üzerinden iki farklı deneyimi yönetmektir.

1. Tek Veritabanı, Çift Katmanlı Erişim

B2B tarafında bayiye özel iskontolu fiyatlar ve zorunlu oturum açma akışı bulunurken, B2C vitrininde ziyaretçilerin kayıt olma zorunluluğu olmadan ürünleri inceleyebilmesi gerekir. Tüm veritabanı sorgularını PDO prepared statements yapısına geçirerek hem SQL injection riskini ortadan kaldırdık hem de katalog filtreleme sorgularını modüler hale getirdik.

2. Ürün Kodu Tabanlı 3:4 Stüdyo Görsel İşleme Algoritması

Perakende e-ticaret arayüzünde ürün kartlarının kaymasını önlemek için tüm görsellerin aynı en-boy oranında (3:4 dikey kadraj) sunulması gerekir. Yönetim panelinden yüklenen ham fotoğraflar PHP GD kütüphanesiyle otomatik olarak işlenir:

// Hedef 3:4 oranına göre merkezden kırpma (Center-Crop) hesabı
$hedefOran = 3 / 4;
$mevcutOran = $genislik / $yukseklik;

if ($mevcutOran > $hedefOran) {
    $yeniGenislik = (int)($yukseklik * $hedefOran);
    $xOffset = (int)(($genislik - $yeniGenislik) / 2);
    $yOffset = 0;
} else {
    $yeniYukseklik = (int)($genislik / $hedefOran);
    $xOffset = 0;
    $yOffset = (int)(($yukseklik - $yeniYukseklik) / 2);
}

İşlenen görseller doğrudan ürün stok koduyla (örneğin PRD-1042-1.webp) adlandırılarak dosya sistemi ile veritabanı arasında ek bir eşleştirme tablosuna ihtiyaç duymadan çoklu galeri desteği sağlandı.
